# Preaw W. Desktop Portfolio

An interactive macOS-inspired portfolio built with React, Vite and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal. Create a production build with `npm run build`.

## Deploy to GitHub Pages

1. Push this project to the `portfolio-project` repository on GitHub.
2. Run `npm install`, then `npm run deploy`.
3. In the repository's **Settings → Pages**, select **Deploy from a branch**, then choose `gh-pages` and `/ (root)`.

The Vite base path is already configured for `https://preaw-warinphorn.github.io/portfolio-project/`.

If the repository is renamed, update `base` in `vite.config.js` to match the new repository name.
